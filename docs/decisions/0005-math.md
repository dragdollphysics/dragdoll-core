# ADR-0005: Use Jolt math types

- **Status:** Accepted
- **Date:** 2026-11-12

## Context
Jolt provides SIMD `Vec3`, `Quat`, `Mat44`. A second math library (GLM) would add conversions everywhere.

## Decision
Use Jolt math types inside the core. Expose only plain C POD structs (`DdVec3`, `DdQuat`, `DdTransform`) at the C ABI. No GLM.

## Consequences
Core code depends on Jolt headers; the ABI stays dependency-free.
