# ADR-0010: Data-driven 16-body rig

- **Status:** Accepted
- **Date:** 2026-11-12

## Context
Characters differ in proportions; hosts have their own skeletons (SA: 32 bones).

## Decision
Rigs are **JSON** files in `packs/rigs/`: 16 bodies (Pelvis, Lower Spine, Upper Spine, Head, L/R Upper Arm, Forearm, Hand, L/R Thigh, Shin, Foot), shapes, joint types and limits, segment masses from **de Leva (1996)**, and a host-skeleton mapping used with `JPH::SkeletonMapper`. No neck or clavicle bodies in v1.

## Consequences
New characters and hosts need data, not code. Neck/clavicles can be added later via a new rig version.

## Sources
de Leva 1996
